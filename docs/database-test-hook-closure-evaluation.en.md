Extend coverage/receipt and document review for SQL/database obligations; deployScripts owns canonical installation and known legacy delegations; hook audit/doctor diagnose effective Git references and package content. Pure logic remains DB-free. Independent review owns necessity, sufficiency, actual production chains and applicability of historical evidence; CLI checks declared deterministic facts.
